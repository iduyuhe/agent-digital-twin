一、项目目标与范围

建成一套自主可控、高保真、可认证的智能数字孪生系统，覆盖"装备—车间—工厂"三层，满足 GB/T 43441 / GB/T 45626-2025 / GB/T 45873-2025 核心技术要求，通过 CESI 成熟度或可信性测评，达到"高保真"二级及以上等级。

技术路线（五元架构）：① 华为 OGG（几何内核，锁定） + ② 解耦 Agent 智能层（通用 MAS 接口，厂商无关） + ③ 仿真保真层（装备 CAE + 工厂级仿真） + ④ 实时数据底座 + ⑤ 模型验证体系。几何内核保自主可控锚点，智能层用通用 MAS 接口保解耦；国产替代不作为 P0 刻意追求项，列为闭环后的个性化迭代。

二、目标场景与边界

场景范围对应标准说明
装备级孪生单机/产线装备几何 + 物理场仿真（应力/温度/振动）+ 预测性维护GB/T 45626-2025数字实体几何由 OGG 承担，物理仿真由 CAE 承担
车间级孪生产线实时映射、状态监控、虚拟调试GB/T 45873-2025实时数据底座承担同步保真
工厂级仿真 ①
新建厂虚拟验证		布局/物流/产线平衡/产能可达性仿真（动工前）GB/T 45873-2025离散事件仿真，避免"建成才发现瓶颈"
工厂级仿真 ②
存量产能优化		产能爬坡推演、瓶颈诊断、排程优化、供应链协同GB/T 45873-2025对接 MES/ERP/SCADA 实时数据（见附录A）
场景边界：工厂级仿真两类场景（新建验证 + 存量优化）并重，均须覆盖。城市/管网等非制造场景不在本期范围，架构可平移但指标需重定。

三、保真等级目标

等级含义本项目目标
高保真 二级满足核心保真维度，可支撑分析预测瞄准二级 / 三级，最终等级依招标/验收要求在该基线上锁定 待确认
高保真 三级全维度高保真 + 虚实验证留痕，可支撑决策闭环

四、量化验收基线（签约约束条款）核心

以下指标在需求基线阶段按目标测评等级锁定为合同验收条款，避免后期争议。

指标目标值性质测评 / 验证方式
几何误差（精密装配）≤ 0.5 mm标尺OGG 模型 vs 实测点云比对（GB/T 45626 几何 6.2）
装备仿真误差率≤ ±0.5%标尺CAE 仿真值 vs 物理试验值（GB/T 45626 仿真 6.1）
工厂级仿真指标（产能/物流节拍预测误差、排程达成率）误差 ≤ X% · 达成率 ≥ Y% 待填标尺仿真输出 vs 历史基线 / 试产实测（GB/T 45873）
实时同步延迟（通用）≤ 200 ms标尺数据底座端到端时延压测（GB/T 43441 同步）
预测 / 操控精度依可信性测评等级测评解耦 Agent 层预测 vs 实际（可信性测评）
决策一致性依可信性测评等级测评Agent 决策 vs 专家/实际处置比对（可信性测评）

标注"标尺"者为第三方测评与行业采购常用高保真阈值，非国标强制数值；标注"测评"者以 CESI 可信性测评等级为准。待填项须在 P0 按目标场景与行业条款补全具体达标值。

五、关键构件选型决策

构件选型决策状态决策依据
① 几何内核华为 OGG（锁定）锁定LGPL 2.1 开源、国产替代 OCCT；几何保真核心锚点
② Agent 智能层厂商无关 + 通用 MAS 接口原则锁定满足 GB/T 45626 诊断/预测指标即可；通用 MAS 接口保解耦，不绑定厂商；国产替代不列入 P0 硬指标
③ 仿真保真层装备 CAE（Simdroid 等国产主力）+ 工厂级仿真引擎（Plant Simulation / AnyLogic，待 POC 定）POC 定见附录B 短名单与附录C POC 大纲；P0 末定首选
④ 实时数据底座开源自建（EMQX+IoTDB，无云优先）/ OPC UA 直采；华为云 IoT 仅作上云选项无云可定承担 GB/T 43441 同步；无云方案即可落地，更契合等保/数据不出域
⑤ 模型验证体系自建流程 + CESI 测评工具链待建落实 GB/T 45626 模型验证 7.3 / 虚实验证 7.5
