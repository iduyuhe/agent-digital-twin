## 2. 总体架构（五元架构）
- 几何层：`factory_sim_core` + 可选 OpenCASCADE / NumPy 网格
- 数据层：`demo_app` 实时传感缓冲（SQLite 队列，等价 EMQX+IoTDB 架构）
- 仿真层：`factory_sim_core`（SimPy 离散事件）+ `p2_cae_fidelity`（FEM/FDM）+ `p2_fem3d`（Hex20 3D 实体）
- 智能层：`p2_intelligence`（诊断/预测/决策三类 Agent）+ 规则引擎兜底 + 可选 Ollama LLM
- 应用层：`demo_unified`（标准 DEMO / 客户定制 / 智能保真 / 集成测评 / L4 闭环）
